# gallery-dl Windows GUI

[Русская версия](./README.ru.md)

Desktop Windows GUI for [`gallery-dl`](https://github.com/mikf/gallery-dl), built with `PySide6`.

## Important

All source code in this repository was generated by AI as part of the development workflow.

## Quick start

- End users: download the latest portable build from [Releases](https://github.com/thomasluntick-debug/gallery-dl-windows-gui/releases).
- Developers: clone the repository and run the app from source.

The packaged Windows release already includes `gallery-dl`. End users do not need to install the original `gallery-dl` separately.

## For users

Download the latest release archive from [Releases](https://github.com/thomasluntick-debug/gallery-dl-windows-gui/releases).

After extracting it, start:

```text
gallery-dl-windows-gui.exe
```

How updates work:
- download the newer release archive;
- extract it into a new folder or replace the old portable folder;
- start the new `gallery-dl-windows-gui.exe`.

You do not need:
- Python;
- git;
- a separate `gallery-dl` installation.

## For developers

### Setup

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -3 -m pip install -U pip
py -3 -m pip install -e .[build]
```

This installs the GUI and `gallery-dl` into the local virtual environment.

### Run from source

```powershell
.\run_gui.cmd
```

Or directly:

```powershell
.\.venv\Scripts\python.exe .\main.py
```

### Build a local EXE

```powershell
.\build_exe.cmd
```

### Build a portable release ZIP

```powershell
.\build_release.cmd
```

Current branch model:
- `main` stores the stable version;
- `test-next` is the current test/development branch;
- releases are published from `main`.

## What is included in the release

The standard release asset is a portable ZIP archive:

```text
gallery-dl-windows-gui-portable-vX.Y.Z.zip
```

Inside it:
- `gallery-dl-windows-gui.exe`
- `gallery-dl-windows-gui-cli.exe`
- `_internal`
- other files produced by the PyInstaller build

Start the packaged app with `gallery-dl-windows-gui.exe`.
The companion CLI EXE is used internally so the GUI can execute the bundled `gallery-dl`.

## Release flow

1. New work is developed in the test branch.
2. A verified version is promoted to `main`.
3. A tag `vX.Y.Z` is created from `main`.
4. Run `.\build_exe.cmd` or `.\build_release.cmd` locally.
5. Publish the generated portable ZIP to GitHub Releases.
6. Release notes describe what changed; the README stays stable.

## Current interface

The current version uses a single main screen without top tabs.

Included now:
- main download screen with queue and live log;
- destination history dropdown;
- file type filters: `All`, `Images`, `Videos`, `Archives`, `Custom`;
- naming templates with live path preview;
- keyword browser for template fields with explanations and insert actions;
- supported sites panel loaded from the official `gallery-dl` GitHub list;
- advanced settings panel with sections for access, filters, post-processing, app/network, and expert options;
- separate history window with a clear action;
- optional per-task log files.

## Limitations

- tasks are executed one after another;
- some advanced `gallery-dl` capabilities still live under expert/raw controls instead of dedicated GUI widgets;
- not every `gallery-dl` option has a visual control yet;
- history is currently a separate window, not a full management screen.
