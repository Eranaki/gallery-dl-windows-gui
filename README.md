# gallery-dl Windows GUI

[Русская версия](./README.ru.md)

Desktop Windows GUI for [`gallery-dl`](https://github.com/mikf/gallery-dl) built with `PySide6`.

This project wraps `gallery-dl` in a desktop interface focused on everyday downloading workflows:
- paste one or more URLs;
- choose a destination folder;
- pick file types;
- configure folder and filename templates;
- review supported sites;
- run checks and downloads without using the command line directly.

## Important notice

All source code in this repository was generated by AI as part of the development workflow.

## Current interface

The current version uses a single main screen without top tabs.

Included now:
- main download screen with queue and live log;
- URL paste/clear actions and sequential task queue;
- destination history dropdown;
- file type filters: `All`, `Images`, `Videos`, `Archives`, `Custom`;
- naming templates with live path preview;
- keyword browser for template fields with explanations and insert actions;
- supported sites panel loaded from the official `gallery-dl` GitHub list;
- advanced settings panel with sections for:
  - access;
  - filters;
  - post-processing;
  - app/network;
  - expert options;
- separate history window with a clear action;
- optional per-task log files;
- EXE build scripts for Windows.

## Setup

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -3 -m pip install -U pip
py -3 -m pip install -e .
```

This installs the GUI and `gallery-dl` into the local virtual environment.

## Run during development

```powershell
.\run_gui.cmd
```

Or directly:

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## Build EXE

```powershell
.\build_exe.cmd
```

Build output:

```text
dist\gallery-dl-windows-gui\
```

Main files after build:

```text
dist\gallery-dl-windows-gui\gallery-dl-windows-gui.exe
dist\gallery-dl-windows-gui\gallery-dl-windows-gui-cli.exe
```

Start the packaged app with `gallery-dl-windows-gui.exe`.
The companion CLI EXE is used internally so the packaged GUI can execute bundled `gallery-dl` commands.

## Current limitations

- tasks are executed one after another;
- some advanced `gallery-dl` capabilities still live under expert/raw controls instead of dedicated GUI widgets;
- not every `gallery-dl` option has a visual control yet;
- the history is currently a separate window, not a full management screen.
