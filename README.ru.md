# gallery-dl Windows GUI

[English version](./README.md)

Графический интерфейс для Windows поверх [`gallery-dl`](https://github.com/mikf/gallery-dl), написанный на `PySide6`.

Проект упаковывает возможности `gallery-dl` в настольное приложение для повседневной работы:
- вставка одной или нескольких ссылок;
- выбор папки сохранения;
- выбор типов файлов;
- настройка шаблонов папок и имен файлов;
- просмотр поддерживаемых сайтов;
- проверка и запуск загрузок без ручной работы в консоли.

## Важное примечание

Весь исходный код этого репозитория был сгенерирован ИИ в рамках процесса разработки.

## Что есть в актуальной версии

Текущая версия использует один главный экран без верхних вкладок.

Сейчас в программе есть:
- главный экран загрузок с очередью и живым журналом;
- вставка и очистка ссылок;
- последовательное выполнение задач;
- выпадающий список последних папок сохранения;
- фильтры по типам файлов: `Всё`, `Изображения`, `Видео`, `Архивы`, `Свое`;
- шаблоны именования с живым предпросмотром пути;
- окно `Доступные поля` с пояснениями и вставкой полей в шаблоны;
- панель `Поддерживаемые сайты`, которая берет список из официального GitHub `gallery-dl`;
- панель `Еще настройки` с разделами:
  - доступ;
  - фильтры;
  - после загрузки;
  - приложение и сеть;
  - настройки для опытных;
- отдельное окно `История` с кнопкой очистки;
- необязательное сохранение логов по задачам в файл;
- сборка Windows `.exe`.

## Установка

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -3 -m pip install -U pip
py -3 -m pip install -e .
```

Команда ставит и сам GUI, и `gallery-dl` в локальное виртуальное окружение.

## Запуск в режиме разработки

```powershell
.\run_gui.cmd
```

Или напрямую:

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## Сборка EXE

```powershell
.\build_exe.cmd
```

Результат сборки:

```text
dist\gallery-dl-windows-gui\
```

Основные файлы после сборки:

```text
dist\gallery-dl-windows-gui\gallery-dl-windows-gui.exe
dist\gallery-dl-windows-gui\gallery-dl-windows-gui-cli.exe
```

Запускать нужно `gallery-dl-windows-gui.exe`.
Второй `.exe` используется приложением внутренне для запуска встроенных команд `gallery-dl`.

## Текущие ограничения

- задачи выполняются по очереди, а не параллельно;
- часть продвинутых возможностей `gallery-dl` пока доступна только через экспертные/raw-настройки;
- далеко не для всех опций `gallery-dl` уже есть отдельные элементы интерфейса;
- история пока сделана как отдельное окно, а не как полноценный экран управления.
