# gallery-dl Windows GUI

[English version](./README.md)

Графический интерфейс для Windows поверх [`gallery-dl`](https://github.com/mikf/gallery-dl), написанный на `PySide6`.

## Важно

Весь исходный код этого репозитория был сгенерирован ИИ в рамках процесса разработки.

## Быстрый старт

- Для пользователей: скачайте последнюю portable-сборку в [Releases](https://github.com/thomasluntick-debug/gallery-dl-windows-gui/releases).
- Для разработчиков: клонируйте репозиторий и запускайте проект из исходников.

В готовом Windows-релизе `gallery-dl` уже встроен. Отдельно устанавливать оригинальный `gallery-dl` пользователю не нужно.

## Для пользователей

Скачайте последний архив релиза из [Releases](https://github.com/thomasluntick-debug/gallery-dl-windows-gui/releases).

После распаковки запускайте:

```text
gallery-dl-windows-gui.exe
```

Как обновляться:
- скачайте новый архив релиза;
- распакуйте его в новую папку или замените старую portable-папку;
- запустите новый `gallery-dl-windows-gui.exe`.

Что не нужно устанавливать отдельно:
- Python;
- git;
- оригинальный `gallery-dl`.

## Для разработчиков

### Установка

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -3 -m pip install -U pip
py -3 -m pip install -e .[build]
```

Эта команда ставит и сам GUI, и `gallery-dl` в локальное виртуальное окружение.

### Запуск из исходников

```powershell
.\run_gui.cmd
```

Или напрямую:

```powershell
.\.venv\Scripts\python.exe .\main.py
```

### Локальная сборка EXE

```powershell
.\build_exe.cmd
```

### Сборка portable ZIP для релиза

```powershell
.\build_release.cmd
```

Текущая модель веток:
- `main` хранит стабильную версию;
- `test-next` — текущая тестовая/рабочая ветка;
- релизы публикуются только из `main`.

## Что входит в релиз

Стандартный релизный файл:

```text
gallery-dl-windows-gui-portable-vX.Y.Z.zip
```

Внутри:
- `gallery-dl-windows-gui.exe`
- `gallery-dl-windows-gui-cli.exe`
- `_internal`
- остальные файлы сборки PyInstaller

Запускать нужно `gallery-dl-windows-gui.exe`.
Второй EXE используется приложением внутренне, чтобы GUI мог запускать встроенный `gallery-dl`.

## Процесс выпуска версий

1. Новые изменения делаются в тестовой ветке.
2. Проверенная версия переносится в `main`.
3. Из `main` создается тег `vX.Y.Z`.
4. Локально выполняется `.\build_exe.cmd` или `.\build_release.cmd`.
5. Сгенерированный portable ZIP загружается в GitHub Releases.
6. README не переписывается под каждый релиз, меняются только Release Notes.

## Что есть в актуальной версии

Текущая версия использует один главный экран без верхних вкладок.

Сейчас в программе есть:
- главный экран загрузок с очередью и живым журналом;
- выпадающий список последних папок сохранения;
- фильтры по типам файлов: `Всё`, `Изображения`, `Видео`, `Архивы`, `Свое`;
- шаблоны именования с живым предпросмотром пути;
- окно `Доступные поля` с пояснениями и вставкой полей в шаблоны;
- панель `Поддерживаемые сайты`, которая берет список из официального GitHub `gallery-dl`;
- панель `Еще настройки` с разделами доступа, фильтров, действий после загрузки, настроек приложения/сети и параметров для опытных;
- отдельное окно `История` с кнопкой очистки;
- необязательное сохранение логов задач в файл.

## Ограничения

- задачи выполняются по очереди, а не параллельно;
- часть продвинутых возможностей `gallery-dl` пока доступна только через экспертные/raw-настройки;
- далеко не для всех опций `gallery-dl` уже есть отдельные элементы интерфейса;
- история пока сделана как отдельное окно, а не как полноценный экран управления.
